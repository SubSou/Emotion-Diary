## 📌 프로젝트에서 활용한 기술

- React 컴포넌트 기반 UI 설계
- React Router DOM을 활용한 페이지 라우팅
- Context API와 useReducer를 활용한 전역 상태 관리
- LocalStorage를 활용한 일기 데이터 저장
- Custom Hook을 활용한 일기 조회 및 페이지 타이틀 관리
- 컴포넌트별 CSS 파일 분리로 스타일 관리
